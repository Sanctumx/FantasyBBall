Placebo note: the plan expected mean about 0. It is -2.0 (about 6 s.e.), as it should be if "second-best streamer in odd
weeks" is a real downgrade rather than a neutral swap. So it shows the pipeline can see a harm of that size; it does not

Gate: gateT(se1, n, delta) = min(0.5*se1/sqrt(n), delta). delta = 0.3 (user, 2026-10-29).
  se1 = 4.2 (the larger of placebo/streaming sd), n = 1000 drafts (about 57 min local at 3.4 s per draft, no PC needed):
  T = min(0.5*4.2/sqrt(1000), 0.3) = 0.066.
  n = 2000: T = 0.047 (about 1.9 h).  n = 200 (pilot size): T = 0.149.
Rule: run the full simulation unless the screen's upper bound is below T. Lineup arm sd is 1.7, so its T is smaller still at
the same n (0.5*1.7/sqrt(1000) = 0.027); use arm-specific se1 if the analyst prefers.
